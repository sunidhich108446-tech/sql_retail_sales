# 🛍️ Retail Sales Analysis Using SQL

## 📌 Project Overview

This project focuses on analyzing retail sales data using **MySQL** to uncover meaningful business insights. The dataset contains transaction-level information, including customer demographics, product categories, sales amounts, quantities, and transaction dates and times.

The objective is to clean the data, explore customer purchasing behavior, analyze sales performance, and answer important business questions using SQL queries.

## 🎯 Project Objectives

- Clean the retail sales dataset by identifying and removing records with missing values.
- Explore the dataset to understand sales transactions, customers, and product categories.
- Analyze sales performance across different product categories and time periods.
- Identify high-value customers and customer purchasing patterns.
- Understand purchasing behavior across gender and age groups.
- Analyze sales trends by month, year, and time of day.

## 🛠️ Tools & Technologies

- **Database:** MySQL
- **Language:** SQL
- **Key Concepts:** Aggregate Functions, Filtering, GROUP BY, ORDER BY, DISTINCT, Common Table Expressions (CTEs), CASE Statements, Subqueries, Date and Time Functions, Window Functions, and Ranking.

## 📂 Dataset Description

The `RetailSales` table contains the following columns:

| Column Name | Description |
|---|---|
| `transactions_id` | Unique identifier for each transaction |
| `sale_date` | Date of the transaction |
| `sale_time` | Time of the transaction |
| `customer_id` | Unique identifier of the customer |
| `gender` | Gender of the customer |
| `age` | Age of the customer |
| `category` | Category of the purchased product |
| `quantity` | Number of units purchased |
| `price_per_unit` | Price per unit of the product |
| `cogs` | Cost of goods sold |
| `total_sale` | Total sales amount for the transaction |

The initial exploration focused on answering three questions:

1. How many sales transactions are present in the dataset?
2. How many unique customers made purchases?
3. What product categories are available in the dataset?

SQL functions such as `COUNT()`, `COUNT(DISTINCT ...)`, and `DISTINCT` were used for exploration.

## 📊 Business Questions & SQL Analysis

The project answers the following nine business questions:

**1. Sales on a Specific Date**

Retrieve all sales transactions made on November 5, 2022.

**2. Clothing Sales in November 2022**

Find clothing transactions where the quantity sold was greater than 10 during November 2022.

**3. Total Sales by Product Category**

Calculate the total sales revenue generated by each product category.

**4. Average Customer Age for Beauty Products**

Determine the average age of customers who purchased products from the Beauty category.

**5. Transactions by Gender and Category**

Count the number of transactions for each gender within every product category.

**6. Best-Selling Month in Each Year**

Calculate monthly sales totals and identify the month with the highest sales in each year using the `RANK()` window function.

**7. Top Five Customers by Total Spending**

Identify the five customers who generated the highest total sales.

**8. Unique Customers by Product Category**

Calculate the number of distinct customers who purchased products from each category.

**9. Sales by Time-of-Day Shift**

Classify transactions into three shifts using a `CASE` statement:

- **Morning:** Before 12:00 PM
- **Afternoon:** 12:00 PM to 5:59 PM, based on the query's hour-based grouping
- **Evening:** 6:00 PM onward

Count the number of transactions in each shift.

## 🚀 How to Run the Project

1. Install and open MySQL Workbench or another MySQL-compatible SQL environment.
2. Import or load the retail sales dataset into the `RetailSales` table.
3. Open `SQL_Retail_Sales_Analysis.sql`.
4. Execute the SQL statements in sequence.
5. Review the result sets to explore sales trends, customer behavior, and category performance.

**Note:** The table creation script defines the schema but does not itself import the dataset. Load the data before running the analysis queries.
